ABOUT THE PROJECT

A closer look at an image’s visual signature.

GenAI Fingerprint is a research prototype for exploring whether visual content and spatial-frequency patterns can help distinguish images from a small set of known generators and real-camera photographs.

Try an image →
01THE ANALYSIS

From image to result

Each image passes through the same measured steps. The app compares the resulting feature vector with patterns learned during training.

  1. 01

    Prepare the image

    The image is decoded, converted to RGB, and center-cropped to 512 × 512 pixels. Smaller images can be padded for the analysis.

  2. 02

    Measure visual content

    DINOv2, a pretrained vision model, converts the crop into 384 numbers that summarize visual content and style.

  3. 03

    Measure frequency patterns

    A second branch analyzes spatial-frequency structure. Its spectrum is compressed to 128 numbers, then combined with 12 hand-designed frequency measurements.

  4. 04

    Compare and report

    The 524 measurements go to an XGBoost classifier. Calibrated class scores and an uncertainty check are returned with the model’s dataset provenance.

02DATA & TRAINING

What the model learns from

The current real-data workflow uses a bounded sample from OwensLab’s CommunityForensics dataset. It covers DALL·E 2, DALL·E 3, Ideogram v2, Imagen 3, Midjourney v6, and real-camera images, plus unsupported-generator and degraded-image examples for uncertainty research.

01Collect & verify

Read image and source metadata from Parquet shards; remove exact duplicate images.

02Keep prompts together

Assign shared normalized prompts to a single split to reduce direct leakage.

03Fit & calibrate

Fit scaling and PCA on training groups; use a separate calibration split.

04Evaluate once held out

Report known-class metrics and out-of-distribution (OOD) rejection separately.

Evaluation boundary

The current commercial source shards contain rows marked test. This project’s prompt-grouped holdout is an internal research evaluation, not an official benchmark score. The dataset does not provide generation-batch IDs or individual source-image IDs, so those sources of overlap cannot be ruled out.

04USE & LIMITS

Local processing, experimental answers

What happens to an upload

The web app accepts requests from the local machine. It reads the image for analysis and does not save the upload as a file. The browser preview is temporary and stays in the page.

What a result means

A score is a model estimate for one supported class, not image provenance. Editing, compression, unfamiliar generators, and dataset differences can change the result. Do not use it as forensic evidence.
